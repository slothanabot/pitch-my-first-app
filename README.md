One entry for make.fun's "A Day of One-Line Pitches" bounty: a single sentence that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun — the friend who is scared of code, whose first app could be ready by tonight, no coding needed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the one-line pitch to `/output/entry.txt` (199 characters, one sentence, deterministic).
